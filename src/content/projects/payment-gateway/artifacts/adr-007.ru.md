## Статус

Принято.

## Контекст

Мобильные клиенты повторяют запросы при обрыве связи; провайдеры по-разному поддерживают дедупликацию.

## Решение

Шлюз требует заголовок `Idempotency-Key` и хранит ответ 24 часа. Повтор с тем же ключом возвращает сохранённый ответ.

```
POST /v1/payments
Idempotency-Key: 7f9c2b1e-…

→ 201 Created  (первый запрос)
→ 201 Created  (повтор, тот же ответ)
```

## Последствия

- Продукты обязаны генерировать ключ
- Нужен Redis для хранения ответов
- Двойные списания исключены на уровне контракта
