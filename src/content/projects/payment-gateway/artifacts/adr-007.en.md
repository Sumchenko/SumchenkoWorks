## Status

Accepted.

## Context

Mobile clients retry requests when the connection drops; providers support deduplication in different ways.

## Decision

The gateway requires an `Idempotency-Key` header and keeps the response for 24 hours. A retry with the same key returns the stored response.

```
POST /v1/payments
Idempotency-Key: 7f9c2b1e-…

→ 201 Created  (first request)
→ 201 Created  (retry, same response)
```

## Consequences

- Products must generate the key
- Redis is needed to store responses
- Double charges are ruled out at the contract level
