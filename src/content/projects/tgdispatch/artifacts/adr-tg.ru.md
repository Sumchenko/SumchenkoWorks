Решения MVP. Проект собран за один день в Claude Code, поэтому решения ниже — о том, что важно было сделать правильно сразу, и о том, что сознательно отложено.

## Стек

Python, FastAPI и aiogram 3 в одном процессе; Groq по OpenAI-совместимому API — и для разбора задач (gpt-oss-120b), и для голосовых (whisper-large-v3-turbo); Notion как трекер; SQLite для резерва. Groq выбран за бесплатный тариф и скорость: для небольшой команды его лимитов хватает.

## Разбор через LLM в режиме JSON

Модель возвращает строго JSON со списком задач, даже если задача одна. Ответ проверяется Pydantic-схемой с перечислениями приоритетов и категорий. При невалидном ответе — одна повторная попытка: ответ модели и уточнение «верни только валидный JSON» добавляются в диалог. Вторая неудача — понятное сообщение пользователю.

## Правила разбиения — в промпте, с примерами

Граница «одна задача или несколько» — главная сложность разбора. В промпт вынесены явные правила и примеры обоих случаев: перечисление через «а ещё» — разные задачи; «в четверг… а нет, давай пятницу» — одна задача с финальным решением. Так же — мягкие сроки («если останется окно на неделе») и сигналы низкого приоритета («по свободе», «если будет время»).

## Даты считает код

Модель возвращает фразу срока, дату считает dateparser с нормализацией русских форм. Подробности и примеры — DOC-01.

## Черновик перед публикацией

Ничего не уходит в Notion без подтверждения. Любое поле правится в Telegram: текстовые — сообщением, приоритет и категория — кнопками, новый срок пересчитывается от времени исходного сообщения. Лишний клик дешевле ошибочной карточки на общей доске.

## Notion с резервом в SQLite

Notion необязателен: без токена бот целиком работает на SQLite. При сбое Notion задача пишется в локальную таблицу-outbox и досылается при старте сервиса и перед каждой новой задачей; первая сетевая ошибка останавливает проход, чтобы не долбить недоступный сервис.

## Уведомления только тем, кто писал боту

Telegram не разрешает боту писать первым. Бот запоминает каждого, кто ему писал, команда `/team` показывает этот список, а при назначении автор честно видит, получилось ли уведомить исполнителя. Поиск по имени сделан в Python, а не через `COLLATE NOCASE`: встроенная коллация SQLite не понимает кириллицу.

## Закрытый доступ

Бот отвечает только по белому списку Telegram user_id — это рабочий инструмент, а не публичный бот.

## Long polling вместо вебхука

Бот запускается фоновой задачей в lifespan FastAPI. Публичный HTTPS-адрес не нужен, сервис поднимается одной командой. Для продакшена правильнее вебхук и хранение состояний вне памяти (замечание З-2).
