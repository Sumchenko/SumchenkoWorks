Решения принимались по ходу дорожной карты из 11 этапов и записывались в таблицу в `docs/ROADMAP.md`. Спорные вопросы разработчик (Claude Code) выносил мне с вариантами и рекомендацией, решение оставалось за мной.

## Клиент — 2026-09-23

React + TypeScript + Vite, CSS Modules и CSS-переменные. Без Tailwind и готовых наборов компонентов — чтобы интерфейс не выглядел как типовой «ИИ-шаблон». Состояние — Zustand, анимации — Motion в духе Fluent / Windows 11.

## Данные: local-first — 2026-09-23

IndexedDB (Dexie) через слой репозиториев — единственный путь записи. Сервер и синхронизация — отдельный этап. Модель данных сразу готовилась к синхронизации: UUIDv7, `updatedAt`, мягкое удаление `deletedAt`.

## Модель задач — 2026-09-23

Подзадачи — полноценные задачи (один уровень вложенности). Две даты: `plannedDate` (когда делать) и `dueDate` (дедлайн). Статусы `open`, `done`, `cancelled`. Таймер можно запустить без задачи.

## Таймер — 2026-09-23

Запись времени в БД — источник истины. Состояние таймера (режим, фаза Pomodoro, пауза) — в localStorage и синхронно между вкладками. Движок — чистые функции с тестами. Записи короче 10 секунд отбрасываются.

## Календарь и семантический зум — 2026-09-23 … 27

Календарь — одна поверхность: камера над бесконечной лентой недель. Уровни детализации перетекают: шкала → полосы → плитки → тепловая карта. Цвет в календаре всегда означает проект. Блок задачи выставляет ей `plannedDate`. Геометрия — чистые функции с тестами. Для телефона — отдельные жесты: тап, долгое нажатие, нижние шторки вместо всплывающих окон.

## Аналитика — 2026-09-23

Ядро — чистые функции в `src/analytics`, общий источник для статистики и AI-ментора. Графики — свои SVG-компоненты на токенах темы. План и факт сравниваются двумя показателями: «выполнение» (время на запланированные задачи в тот же день) и «точность» (пересечение с запланированными часами).

## Бэкенд и синхронизация — 2026-09-23

Supabase: Postgres, Auth, Realtime. Гостевой режим без аккаунта с мягкими приглашениями войти. Исходящая очередь изменений на клиенте, серверный счётчик ревизий для выборки изменений, last-write-wins по `updatedAt`, удаление — надгробиями. Доставка — Realtime плюс догоняющая синхронизация при запуске и возврате в сеть.

## Хостинг — 2026-09-25

Сайт и прокси к Supabase — Caddy на VPS в Германии, бэкенд — Supabase Cloud. Выкладка — GitHub Actions на каждый push в main: проверки → миграции → атомарное переключение релиза → smoke-тест. Браузер ходит только на наш домен (Supabase под `/sb`, ссылки из писем — `/auth/confirm`), чтобы работать там, где хост Supabase недоступен.

## AI-ментор — 2026-09-27

Сервер ментора — Node-сервис на нашем VPS за Caddy, без доступа к БД: сводку данных собирает приложение ядром аналитики. Провайдеры — по OpenAI-совместимому протоколу, цепочка Groq → Gemini Flash → Gemini Flash-Lite с автопереключением. Порядок выбран по замерам: Groq быстрее и лучше планирует, Gemini Flash на бесплатном тарифе часто перегружен. Доступ всем, лимит по IP и общий дневной лимит. Ключи только на сервере. Действия из чата — только с подтверждением.

## Ментор обучения — 2026-09-27

Два режима: «Ментор» (цели обучения) и «Ассистент» (только планирование). Знакомство — разговор с кнопками-вариантами, итог — карточка «Я правильно понял?». План — этапы с результатами и задачи на 1–2 недели, дальше еженедельная встреча подстраивает его под реальный темп. Мини-проверка знаний в конце этапа. Дни занятий — настройка цели: любая предложенная дата сдвигается на ближайший день занятий кодом, не полагаясь на модель.
