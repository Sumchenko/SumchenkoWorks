## Таблица `records` (сервер, PostgreSQL)

Одна строка — одна запись пользователя: задача, блок календаря, запись таймера и т. д.

| Поле | Тип | Обязательное | Ограничения | Что означает |
| --- | --- | --- | --- | --- |
| `id` | uuid | да | Первичный ключ | Идентификатор записи. Создаётся на устройстве, поэтому запись можно создать без интернета |
| `user_id` | uuid | да | Внешний ключ на пользователя. По умолчанию — текущий пользователь | Владелец записи |
| `collection` | text | да | Только значения из списка: `projects`, `tags`, `tasks`, `timeEntries`, `timeBlocks`, `goals`, `mentorNotes` | Что это за запись |
| `doc` | jsonb | да | — | Сама запись со всеми полями (название задачи, время блока и т. д.) |
| `updated_at` | bigint | да | Время в миллисекундах | Когда запись изменили в последний раз. По нему выбирается более новая версия |
| `deleted_at` | bigint | нет | Время в миллисекундах | Когда запись удалили. Пусто — запись не удалена |
| `rev` | bigint | да | Заполняет сервер, при каждом изменении — новый номер | Номер изменения. По нему устройство запрашивает «всё новое после номера N» |

### Индексы

| Индекс | Поля | Зачем |
| --- | --- | --- |
| Первичный ключ | `id` | Быстро найти запись при сохранении |
| `records_user_rev` | `user_id`, `rev` | Быстро выбрать «записи этого пользователя после номера N» |

**Правила доступа.** В базе включено правило: пользователь читает и изменяет только строки, где `user_id` -
это он. Удалять строки запрещено всем, удаление — только через `deleted_at`.

## Очередь `outbox` (устройство, IndexedDB)

Список изменений, которые ещё не отправлены на сервер.

| Поле | Тип | Обязательное | Ограничения | Что означает |
| --- | --- | --- | --- | --- |
| `key` | string | да | Первичный ключ, вид `tasks:<id>` | Одна строка на запись, сколько бы раз её ни меняли |
| `table` | string | да | Название таблицы | Где лежит изменённая запись |
| `id` | string | да | — | Какая запись изменена |
| `seq` | number | да | Растёт при каждом изменении | Порядок отправки |

## Служебное состояние `syncState` (устройство)

| Ключ | Что хранит |
| --- | --- |
| `cursor` | Номер `rev` последнего полученного изменения |
| `owner` | Какому аккаунту принадлежат данные на устройстве. Пусто — данные гостя |

## Поля в запросе `push_records`

| Поле запроса | Куда сохраняется |
| --- | --- |
| `id` | `records.id` |
| `collection` | `records.collection` |
| `doc` | `records.doc` |
| `updatedAt` | `records.updated_at` |
| `deletedAt` | `records.deleted_at` |
