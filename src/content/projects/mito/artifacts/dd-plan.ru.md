## Таблица `timeBlocks` — блоки календаря (устройство)

Сюда записываются блоки, которые пользователь добавил из плана.

| Поле | Тип | Обязательное | Ограничения | Что означает |
| --- | --- | --- | --- | --- |
| `id` | uuid | да | Первичный ключ | Идентификатор блока |
| `taskId` | uuid | нет | Ссылка на задачу. Задача должна существовать | Какая задача запланирована. Пусто — перерыв или событие |
| `title` | string | если нет `taskId` | Не пустое | Название блока без задачи, например «Обед» |
| `start` | datetime | да | — | Начало блока |
| `end` | datetime | да | Позже `start` | Конец блока |
| `kind` | string | да | `task`, `event`, `break`, `routine` | Тип блока: задача, событие, перерыв, ритуал |
| `origin` | string | да | `user` или `mentor` | Кто создал блок: пользователь или AI-ментор |

Блоки могут пересекаться: план — это намерение, а не факт.

**Индексы:** `taskId` — найти блоки задачи; `start`, `end` — найти блоки за период (например, за день).

## Таблица `tasks` — задачи (устройство)

Поля, которые использует план дня.

| Поле | Тип | Обязательное | Ограничения | Что означает |
| --- | --- | --- | --- | --- |
| `id` | uuid | да | Первичный ключ | Идентификатор задачи |
| `title` | string | да | Не пустое | Название |
| `status` | string | да | `open`, `done`, `cancelled` | В план попадают только открытые задачи (`open`) |
| `priority` | int | да | 0-3, по умолчанию 0 | Важность: 0 — нет, 3 — высокая |
| `estimateMin` | int | нет | Больше 0 | Сколько минут займёт задача по оценке пользователя |
| `plannedDate` | date | нет | Формат `ГГГГ-ММ-ДД` | Когда пользователь собирается делать задачу. Ставится автоматически при добавлении блока |
| `dueDate` | date | нет | Формат `ГГГГ-ММ-ДД` | Дедлайн. Задачи с близким сроком идут в план первыми |

**Индексы:** `plannedDate`, `dueDate` — быстро найти задачи на день и с близким сроком.

## Таблица `daily` — лимит запросов (сервер ментора, SQLite)

| Поле | Тип | Обязательное | Ограничения | Что означает |
| --- | --- | --- | --- | --- |
| `key` | text | да | Первичный ключ вместе с `day` | Хеш адреса пользователя. Строка `*` — общий счётчик по всем пользователям |
| `day` | text | да | Первичный ключ вместе с `key`, дата | За какие сутки счётчик |
| `count` | integer | да | — | Сколько запросов уже сделано |

Лимиты: 60 запросов в сутки с одного адреса, 800 в сутки на всех. Лимит «10 в минуту» хранится в памяти
сервера, а не в таблице.

## Как поля ответа превращаются в блок календаря

| Поле в ответе сервера | Поле в `timeBlocks` |
| --- | --- |
| `taskRef` (например, `t1`) | `taskId` — приложение подставляет настоящий id задачи |
| `title` | `title` |
| `date` + `start` | `start` |
| `date` + `end` | `end` |
| — | `origin` = `mentor` |
| `reason` | Не сохраняется, показывается только в плане |
