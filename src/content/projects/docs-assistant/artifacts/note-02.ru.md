## Вопрос

Как размер и способ разбиения влияют на точность поиска по технической документации.

## Варианты

- Фиксированный размер с перекрытием
- По заголовкам Markdown
- Комбинированный: заголовки + ограничение длины

## Промежуточный вывод

Демонстрационный пример: разбиение по заголовкам с ограничением длины даёт более цельные фрагменты.
